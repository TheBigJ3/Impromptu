Impromptu

Impromptu is a Chrome extension powered by Google’s built-in AI Prompt API. It analyzes the context of the website you’re on and intelligently selects the best “Tool Card” to help you complete your task — from summarizing text to translating pages.

Setup Instructions

Clone or download the repository
git clone https://github.com/
<your-username>/impromptu.git
cd impromptu

Install dependencies
npm install

Build the project
npm run build

Load the extension in Chrome

Open chrome://extensions/

Enable Developer mode

Click Load unpacked

Select the dist/ folder created after the build step

Keybinds

Trigger Impromptu:
Press ";" (semicolon) to activate.
Works best when paired with Meta + ; (Command on Mac / Windows key on Windows).

Notes

Make sure Chrome’s built-in AI features (Prompt API) are enabled.
